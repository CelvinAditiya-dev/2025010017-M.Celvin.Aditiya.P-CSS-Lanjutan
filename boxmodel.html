Praktik 1 dan 4 — Ukuran Box

Box model terdiri dari content, padding, border, dan margin. Coba ubah nilai CSS pada kelas di bawah ini.

Konten Box Model
.model-box {
  width: 300px;
  min-height: 100px;
  padding: 20px;
  border: 5px solid #2563eb;
  margin: 20px;
  background: #dbeafe;
  box-sizing: content-box;
}

Praktik 2 — Padding Multi Nilai

A — padding: 20px
B — padding: 10px 30px
C — padding: 10px 20px 30px
D — padding: 5px 10px 15px 20px

Urutan empat nilai adalah atas, kanan, bawah, kiri (top, right, bottom, left).

Praktik 3 — Margin

Box 1 — margin-bottom: 10px
Box 2 — margin: 20px 0
Box 3 — margin-top: 30px

margin: 0 auto dapat memusatkan elemen block yang mempunyai lebar tertentu pada ruang horizontal yang tersedia.

Praktik 17 — Content-box dan Border-box

content-box: lebar total bertambah karena padding dan border
border-box: padding dan border termasuk dalam width
